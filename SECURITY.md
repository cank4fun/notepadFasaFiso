# Security Policy

## Supported versions

Security fixes are provided for the latest public release of notepadFasaFiso.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed security vulnerability.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Open **Advisories**.
3. Choose **Report a vulnerability**.

Include the affected version or commit, reproduction steps, expected and observed behavior, and any proof-of-concept material that helps reproduce the issue.

Please avoid publishing exploit details until a fix or coordinated disclosure is ready.
