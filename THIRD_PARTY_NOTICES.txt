Linux AppImage dependency set
-----------------------------
The Linux AppImage additionally bundles shared libraries from the Debian build
baseline selected for the release. That runtime closure depends on the exact
build host and is therefore inventoried from the finished AppDir rather than
maintained as a hand-written static list.

During AppImage packaging, tools/release/collect-appimage-licenses.sh:

1. inventories each bundled shared library,
2. maps it to the installed Debian package that supplied it,
3. records the exact binary and source package versions,
4. copies that package's /usr/share/doc/<package>/copyright file, and
5. copies Debian's /usr/share/common-licenses directory so references from
   Debian copyright files remain resolvable inside the AppImage.

The generated material is stored inside the AppImage under:

  /usr/share/doc/notepadFasaFiso/

including BUNDLED_DEBIAN_PACKAGES.txt, BUNDLED_DEBIAN_SOURCES.txt,
debian-package-copyrights/ and common-licenses/.

For bundled Debian libraries whose licenses require corresponding source,
tools/release/collect-appimage-sources.sh retrieves the exact Debian source
package artifacts listed in BUNDLED_DEBIAN_SOURCES.txt. The resulting
`notepadFasaFiso-appimage-corresponding-source.tar.gz` is part of the Linux
binary release and must be published beside the AppImage.

AppImage type2 runtime
----------------------
The AppImage file itself is prefixed with the AppImage type2 runtime. The
release tooling accepts only the pinned x86_64 runtime whose SHA-256 is
`1cc49bcf1e2ccd593c379adb17c9f85a36d619088296504de95b1d06215aebbf`,
corresponding to AppImage/type2-runtime commit
`75849dce7cc37e4319b633df1f116ca895c71a12`.

The runtime's own license and the permissive notices needed for its musl,
squashfuse, zstd and mimalloc components are under
third_party/licenses/appimage-runtime/. The existing zlib notice also applies
to the runtime's zlib component. The runtime statically links libfuse 3.15.0
library code under LGPL-2.1. The AppImage embeds a copy of the LGPL-2.1 license
under `usr/share/doc/notepadFasaFiso/common-licenses/LGPL-2.1`, and the runtime
source bundle below carries the exact libfuse source plus the patch/build
materials used by the pinned type2-runtime source tree.

tools/release/collect-appimage-runtime-sources.sh verifies the exact runtime
binary hash and creates `notepadFasaFiso-appimage-runtime-source.tar.gz`,
containing the pinned type2-runtime source, the exact libfuse 3.15.0 source,
and the exact squashfuse 0.5.2 source. Publish this runtime source bundle beside
the AppImage and the Debian corresponding-source bundle.

Packaging fails if a bundled shared library cannot be mapped to an installed
Debian package with an available copyright notice, if the recorded exact Debian
source package cannot be retrieved, or if the supplied AppImage runtime does
not match the pinned runtime hash.
